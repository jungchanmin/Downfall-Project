> 운영 문서 v0.1.0 · Director는 STEP 1–4의 비서 세션 운영 체계 도입과 GitHub 중심 작업 추적을 승인했다. 이 자료는 운영 보조 문서이며 Gameplay 정본이나 Gameplay Owner가 아니다. 상위 Governance와 최신 명시적 Director 지시가 우선한다. GitHub PR의 검토·병합 상태와 운영 기준의 승인 상태는 별도로 확인한다.

# DOWNFALL — TASK CONTRACT

Task ID / Name: [기존 ID 우선]  
Assigned Role / Coordinator: [역할]  
Goal: [목표]  
Source of Truth / Owners: [ID, 경로, Authority, 버전]  
Base Branch / verified Base Commit: [기준]  
Working Branch / Head: [있을 때]  
Read Scope: [범위]  
Write Scope: [경로 또는 없음]  
Protected Scope: [변경 금지]  
Approved Constraints / Evidence: [결정과 근거]  
Unresolved Requirements: [미정]  
Dependencies / parallel work / integration order: [선행 조건과 순서]  
Deliverables: [산출물]  
Acceptance Criteria: [검수 가능한 기준]  
Validation Requirements: [증거와 한계]  
Required Approvals: [승인권자 및 결정]  
Handoff: [전달 대상 및 저장 위치]

확인할 수 없는 항목은 UNVERIFIED로 기록한다. 이 명세는 정본이나 Director 결정을 대체하지 않는다.
