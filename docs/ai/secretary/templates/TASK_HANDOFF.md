## 10. Recovery Instructions

새 세션에서는:

1. 공식 Read Order를 수행한다.
2. CONTEXT_CURRENT의 최신 상태를 확인한다.
3. 해당 작업의 Owner를 재확인한다.
4. Git Head와 작업 결과의 실제 반영 여부를 확인한다.
5. 승인된 범위를 유지하면서 Next Action을 수행한다.

이 Handoff는 정본이 아닌 복구용 기록이다.
