# 생존자 굴복 전용 기술 작성 규칙 v1.0

## 1. 문서 목적

이 문서는 특수 굴복페이즈용 생존자 기술을 신규 작성하거나 기술 도감에 등록할 때 사용하는 제작 규칙이다.

기술 데이터 스키마의 정본은 `MECH_R18_Skill_Catalog_Core`와 `MECH_R18_Skill_Data_Contract`가 소유한다. 본 문서는 해당 필드를 실제 콘텐츠로 채울 때의 의미, 품질 기준, 분류 경계와 검수 절차를 소유한다.

```text
이 문서
= 기술을 어떻게 설계하고 검수하는가

Skill Catalog Core / Data Contract
= 기술을 어떤 필드로 저장하고 처리하는가
```

---

## 2. 정본 우선순위

생존자 굴복 기술 작성 규칙이 다른 문서와 충돌할 경우 다음 순서를 따른다.

1. `MECH_R18_Submission_Resource_System`
2. `MECH_R18_Body_Sensitivity_System`
3. `MECH_R18_Submission_Core_System`
4. `MECH_R18_Skill_Catalog_Core`
5. `MECH_R18_Gate_Tag_Standard`
6. `MECH_R18_Survivor_Submission_Skill_Design_Rules`
7. 개별 기술 도감·캐릭터 기술 목록

개별 기술은 상위 규칙을 명시적으로 오버라이드할 수 있으나, 반드시 오버라이드 필드와 출처를 기록한다.

---

## 3. 굴복 전용 기술 판별 기준

신규 기술이 특수 굴복페이즈 전용 기술로 분류되려면 다음 조건을 모두 만족해야 한다.

### 3.1 필수 조건

1. 특수 굴복페이즈의 자원·부위·자세·점유 중 하나 이상을 직접 다룬다.
2. 기술의 핵심 효과가 일반전투의 체력·정신력 피해, 무기 공격, 일반 회피, 도주가 아니다.
3. 괴물 탈진력 감소, 생존자 굴복도 보호·회복, 절정도 관리, 부위 감응, 자세·점유·게이트 조작 중 하나 이상의 전술 목적을 가진다.
4. 성적 교전행위와 해당 행동의 위험·비용·반응을 기술 정의에 포함한다.
5. 일반전투 기술과 명칭·연출만 다르고 효과가 동일한 복제 기술이 아니다.

### 3.2 굴복 전용으로 인정하지 않는 예

- 무기로 찌르기
- 단순 밀치기
- 일반 회피
- 거리 벌리기
- 일반적인 관절기
- 체력 회복
- 도주 준비
- 일반전투 상태이상만 부여하는 기술

위 행동은 굴복페이즈 안에서 자세·점유 해제의 일부 동작으로 Narration에 포함될 수는 있지만, 기술의 정체성이 되어서는 안 된다.

### 3.3 경계 사례

`기승위 역전`처럼 물리적 자세 전환이 포함된 기술은 다음 조건을 만족할 때 굴복 전용으로 인정한다.

```text
물리적 자세 전환
→ 괴물의 굴복 약점 부위를 공략
→ 탈진력·감응도·주도권에 영향
```

단순히 상대를 넘어뜨리고 끝나면 일반전투 기술이다.

---

## 4. 커맨드 5분류 공통 원칙

`Service / Tease / Domination / Absorption / Defiance`는 실제 행동명이 아니라 전술 역할이다.

```text
커맨드 분류
≠ 기술명
≠ 캐릭터 보유 기술
≠ 자동 지급 기술
```

- 실제 기술은 Skill Catalog에 개별 ID로 등록한다.
- 생존자의 사용 가능 기술은 `known_skills`와 해금 규칙이 결정한다.
- 모든 성인 생존자가 동일한 기술을 자동 보유하지 않는다.
- 캐릭터마다 초기 기술 수, 분류 비중, 위험 수용 방식이 달라질 수 있다.
- 공용으로 제공되는 것은 버티기·도움 요청·교대 요청 등 시스템 안전 행동뿐이다.

## 5. Service 작성 규칙

### 5.1 역할

Service는 생존자가 주도권을 보유했을 때 괴물의 특정 부위를 안정적으로 공략해 탈진력을 감소시키는 기본 공격 역할이다.

### 5.2 필수 설계 요소

- 명확한 목표 부위
- 명확한 행동 부위
- 기본 탈진력 피해
- 감응 진행값
- 자기 절정 비용 또는 무비용 근거
- 괴물의 대응 행동
- 자세·점유 조건

### 5.3 권장 특성

- 낮거나 중간 수준 위력
- 비교적 낮은 실패 위험
- 특정 부위 반복 공략에 유리
- 부위 보호·반복 예측에는 취약
- 주도권을 자동 유지하지 않는 것이 기본

### 5.4 기술 예시 범주

- 키스
- 프렌치 키스
- 가슴 주무르기
- 핸드잡
- 구강 자극
- 전신 밀착 자극
- 괴물 특수 기관 자극

### 5.5 금지 사항

- 모든 부위를 동일 위력으로 공략하는 만능 Service
- 자기 비용 없이 Major급 피해를 반복하는 기술
- 대응 행동이 존재하지 않는 자동 피해 기술
- 일반전투 약공을 이름만 바꾼 기술

## 6. Tease 작성 규칙

### 6.1 역할

Tease는 괴물의 성적 공격, 접근, 점유 또는 자세 강제를 유도하고 완성 직전에 역이용하는 고위험 카운터 기술이다.

### 6.2 핵심 결과

정확한 카운터 성공은 원칙적으로 다음을 제공한다.

```text
괴물 공격 취소
+ 괴물 탈진력 피해 또는 감응 진행
+ 카운터 측 주도권 획득
```

### 6.3 필수 설계 요소

- `counter_profile`
- 필수 Gate Tag
- 금지 Gate Tag
- 사용 가능한 행동 부위
- 대응 가능한 대상 부위
- 성공·대성공 보상
- 부분 일치 시 허용 효과
- 실패 시 자기 굴복·절정 위험

### 6.4 작성 원칙

- 단순 방어·회피가 아니라 상대의 접근을 성적 교환 안에서 역이용해야 한다.
- 기술명과 설명만으로 어떤 공격을 카운터하는지 추론 가능해야 한다.
- 모든 Chest 공격을 카운터하는 식의 과도한 범용성을 피한다.
- 자세·방향·점유·공격 부위 중 최소 둘 이상을 요구하는 것을 권장한다.

### 6.5 부분 일치

부분 일치는 완전 카운터가 아니다.

허용 후보:

- 굴복도·절정도 피해 일부 경감
- 자세 강제 방지
- 특정 부위 점유만 방지
- 공격을 중립 합으로 전환

부분 일치만으로 자동 주도권 탈취를 허용하지 않는다.

## 7. Domination 작성 규칙

### 7.1 역할

Domination은 우세 자세를 확정하거나 불리한 자세를 뒤집은 뒤 괴물의 약점 부위를 집중 공략하는 고위력·고위험 기술이다.

### 7.2 필수 특징

- 높은 탈진력 피해 또는 강한 Control 효과
- 자세·주도권·자원 임계 조건
- 실패 시 명확한 자기 피해
- 자기 절정 비용
- 피니셔 여부
- 공격자 효과 우선 적용 여부

### 7.3 일반 Domination과 역전 Domination

#### 우세형

- 생존자 주도권 필요
- 특정 자세 필요
- 약점 부위 또는 과자극 부위 공략

#### 역전형

- 피주도권 상태 필요
- 일정 굴복도 손실 또는 점유 상태 필요
- 사용 가능한 행동 부위가 남아 있어야 함
- 완전 구속 상태에서는 기본적으로 사용 불가

### 7.4 결정타 설계

고위력 Domination은 자기 굴복·절정 비용을 가질 수 있다. 대상 탈진력을 0으로 만들면 공격자 효과 우선 규칙에 따라 승리를 먼저 확정한다.

### 7.5 금지 사항

- 조건 없는 즉시 결착
- 모든 자세에서 사용 가능한 범용 피니셔
- 실패 비용이 없는 고위력 기술
- Service보다 안전하면서 더 강한 상위호환

---

## 8. Absorption 작성 규칙

### 8.1 역할

Absorption은 괴물의 체액·분비물·에너지·기관 효과를 받아들여 회복, 전환, 탈진 피해 또는 특수 자원으로 바꾸는 양날 기술이다.

### 8.2 필수 설계 요소

- 흡수 가능한 공격축 또는 물질
- 입력 효과와 출력 효과
- 자기 절정 비용
- 오염·Mutation·기벽 위험
- 실패·과잉 흡수 결과
- 반복 사용 제한
- Memory Log·기벽 Return 연결

### 8.3 기본 방향

```text
괴물 Fluid·특수 공격
→ 흡수 선택
→ 일부 피해 수용
→ 굴복도·절정도·탈진력·상태로 전환
```

### 8.4 권장 위험

- 높은 자기 절정 비용
- 오염 또는 변이 표식
- 특정 기벽 획득 위험
- 전투 후 후유 상태
- 동일 전투 반복 효율 감소

### 8.5 금지 사항

- 모든 공격을 무효화하며 회복하는 만능 기술
- 위험 없이 굴복도와 절정도를 동시에 대량 회복
- 입력 공격축과 무관한 임의 전환

Absorption은 현재 페이퍼 테스트가 부족하므로 실제 기술 도감 대량 작성 전 Fluid·Mutation 수직 테스트를 우선한다.

## 9. Defiance 작성 규칙

### 9.1 역할

Defiance는 굴복도 보호·제한 회복, 절정도 감소, 점유·구속·인지 상태 해제, 연속 주도권 차단과 다음 공격 준비를 담당한다.

### 9.2 기본 효과 후보

- 굴복도 피해 감소
- 굴복도 제한 회복
- 절정도 감소
- 감응 진행 감소
- 점유·구속 단계 약화
- Cognition 상태 해제
- 괴물의 몰아붙임 차단
- 다음 Tease·Service 보정

### 9.3 굴복도 회복

- 자연 회복은 없다.
- 기본 회복 권장량은 성공 시 `+1`이다.
- 행동권·주도권·쿨타임·자기 비용 중 하나 이상을 요구한다.
- 반복 회복으로 교착이 발생하지 않도록 제한한다.

### 9.4 절정 여운

기본 Defiance는 절정 여운의 행동 스킵을 무효화하지 못한다.

행동 스킵 예외는 다음에만 허용한다.

- 상위 Defiance
- 생존자 고유 능력
- 기벽 Return
- 동료 지원
- 명시적 일회성 효과

### 9.5 금지 사항

- 공격 취소·탈진 피해·주도권 획득을 모두 동시에 제공
- Tease보다 강한 카운터
- 비용 없는 반복 회복
- 모든 상태를 한 번에 해제하는 만능 정화

## 10. 기술명 작성 원칙

### 10.1 기본 기술명

기본 기술은 플레이어가 행동을 즉시 이해할 수 있는 보편적이고 직접적인 명칭을 사용한다.

권장:

- 키스
- 프렌치 키스
- 가슴 주무르기
- 핸드잡
- 구속 풀기
- 기승위 역전

지양:

- 숨결 잇기
- 손끝의 압박
- 붉은 파동
- 심연의 교감

완곡하거나 문학적인 표현은 기술의 실제 행동과 목표 부위를 숨겨 테스트와 UI 이해를 방해한다.

### 10.2 고유 변종명

캐릭터 고유 기술이나 기벽 변종은 다음 형식을 권장한다.

```text
기본 행동명
+ 고유 변종명
```

예:

```yaml
display_name: 숨 막히는 프렌치 키스
base_action_name: 프렌치 키스
```

UI·도감에는 두 정보를 모두 제공할 수 있어야 한다.

## 11. 부위와 행동 부위 작성 원칙

### 11.1 목표 부위

기술은 `body_part.group`과 필요할 경우 `specific_part`를 지정한다.

```yaml
target_parts:
  - group: Mouth
    specific_part: Tongue
```

대분류 기술은 여러 개체에 폭넓게 적용하고, 세부 부위 기술은 약점 집중·피니셔·고유 변종에 사용한다.

### 11.2 행동 부위

생존자가 실제로 사용하는 부위를 별도로 기록한다.

```yaml
action_parts:
  - Mouth
  - Hand
```

대상 부위와 행동 부위를 혼합한 `required_parts` 필드는 사용하지 않는다.

### 11.3 비인간형 대상

괴물에게 해당 부위가 없으면 기술을 사용할 수 없다.

- 성기 없는 괴물에게 핸드잡 불가
- 가슴 없는 괴물에게 가슴 주무르기 불가
- SpecialOrgan을 가진 괴물은 실제 세부 기관을 선언

상황 기반 기술 접근 시스템은 현재 대상에게 유효하지 않은 기술을 우선 표시하지 않는다.

## 12. 자원 효과 작성 규칙

모든 기술은 직접 효과와 사용자 비용을 분리해 기록한다.

```yaml
resource_effects:
  submission_damage: 0
  submission_recovery: 0
  exhaustion_damage: 2
  climax_gain_target: 0
  climax_reduction: 0

self_resource_costs:
  self_climax_cost: 1
  failure_self_climax_cost: 0
  critical_failure_self_climax_cost: 2
  self_submission_cost: 0
```

### 12.1 절정 증가 등급

```yaml
climax_gain_grade: Standard
climax_gain_cap_override: null
```

- Minor: 최대 2
- Standard: 최대 4
- Major: 최대 5
- Finisher: 기술별 개별값

### 12.2 감응 진행

```yaml
sensitivity_progress:
  grade: Standard
  amount: 2
```

- Minor 기본 +1
- Standard 기본 +2
- Major·Finisher 개별 정의

### 12.3 자기 비용

성공·실패·대실패 비용을 별도 필드로 작성한다. 공통 비율 계산으로 대체하지 않는다.

## 13. 약점과 감응도 상호작용

### 13.1 약점

기술은 특정 약점 유형을 이용할 수 있다.

- `Exhaustion`
- `Control`
- `ClimaxSensitivity`

약점 효과와 기술 기본 위력을 같은 필드에 중복 기록하지 않는다.

### 13.2 감응도

감응도 효과는 `MECH_R18_Body_Sensitivity_System`의 기본 프로필을 따른다.

생존자 대상:

- Sensitive: 절정도 +1
- Overstimulated: 절정도 +1, 굴복도 피해 +1

괴물 대상:

- Sensitive: 탈진력 피해 +1
- Overstimulated: 탈진력 피해 +1, 안정성 -1

### 13.3 반복 공략

기술 설명에는 동일 부위 반복 시 상대가 사용할 수 있는 보호 행동 또는 대응 변화를 포함해야 한다.

기술이 감응 상승 이득만 제공하고 반복 대응책을 전혀 허용하지 않으면 검수 실패로 처리한다.

## 14. 자세·점유·게이트 작성 규칙

### 14.1 자세

```yaml
valid_postures:
  - Front
  - Mount

posture_force: null
```

기술 사용 전 자세와 결과 자세를 구분한다.

### 14.2 점유

기술이 Mouth·Hand·LowerBody·WholeBody를 점유하면 다음을 명시한다.

- 점유 주체
- 점유 대상 부위
- 봉쇄되는 행동 부위
- 해제 조건
- 지속 방식

### 14.3 Gate Attack

자세 강제·부위 점유·구속을 발생시키는 기술은 `gate_attack`을 필수로 가진다.

### 14.4 Tease Counter

Tease는 `counter_profile`을 필수로 가진다.

### 14.5 완전 구속

완전 구속 중 사용할 수 있는 기술은 반드시 명시적 예외 필드를 가진다. 기본값은 사용 불가다.

## 15. 위력·안정성·쿨타임 작성 원칙

### 15.1 위력

위력은 기술의 모든 장점을 뜻하지 않는다.

```text
위력
= 직접 자원 효과의 기본 강도
```

자세 강제, 주도권 유지, 상태이상, 감응 진행은 별도 효과로 기록한다.

### 15.2 안정성

안정성은 실패 위험과 대응 난도를 표현한다.

- 안정형 Service: 높음
- Tease: 조건 충족 시 높음, 오판 시 낮음
- Domination: 낮음 또는 조건부
- Absorption: 대상 공격에 따라 변동
- Defiance: 상태에 따라 중간 이상

### 15.3 쿨타임

쿨타임은 강기술 반복 방지 수단이지 모든 기술에 의무 적용되는 자원이 아니다.

다음 중 하나 이상을 가진 기술은 쿨타임 또는 사용 제한을 검토한다.

- 높은 탈진력 피해
- 행동 스킵 예외
- 완전 구속 해제
- 즉시 감응 단계 상승
- 주도권 체인 유지
- 피니셔

---

## 16. 전조 작성 규칙

### 16.1 전조의 목적

전조는 플레이어가 상대의 기술명 자체가 아니라 행동의 방향, 목표 부위, 자세 강제 가능성을 추론하도록 돕는다.

### 16.2 기술별 필요성

모든 기술에 전용 전조 Bark를 만들지 않는다.

- 첫 조우 기술: 상세 전조 Narration + 불확실한 Bark
- 확인된 기술: 짧은 동작 전조 + 인식 Bark
- 연속 공격: 상태 Narration만으로 충분하면 Bark 생략
- 피니셔: 상세 전조 + 위험 Bark + UI 경고
- 의복 손상기: 신체가 아니라 천·끈·여밈을 노리는 고유 단서

### 16.3 생존자 기술 전조

생존자 기술도 괴물 AI가 대응할 수 있도록 준비 동작을 가질 수 있다. 단, 플레이어에게 자기 기술을 설명하는 Bark를 강제로 출력하지 않는다.

### 16.4 금지 사항

- 기술명을 그대로 읽는 전조
- 정답 Gate Tag를 문장으로 나열
- 매 사용마다 동일한 긴 문장 출력

## 17. Narration·Bark 계약

### 17.1 기술 데이터가 제공해야 하는 연출 태그

```yaml
narration_tags:
  preparation: []
  contact: []
  success: []
  failure: []
  critical_success: []
  critical_failure: []
  posture_change: []
  resource_reaction: []

bark_trigger_tags:
  - WeaknessDiscovered
  - PerfectCounter
  - CriticalSuccess
  - SelfMistake
  - DangerThreshold
```

기술 데이터에 완성 문장 전체를 대량 저장하기보다 연출 시스템이 조합할 수 있는 의미 태그를 우선 제공한다.

### 17.2 기본 기술 Narration

다음 정보가 읽는 것만으로 파악되어야 한다.

- 누가 어떤 부위를 사용했는가
- 어떤 부위를 목표로 했는가
- 왜 성공하거나 실패했는가
- 자세·점유가 어떻게 바뀌었는가
- 자원 변화가 신체 반응으로 어떻게 나타났는가

### 17.3 Bark

Bark는 플레이어 대상 안내문이 아니라 캐릭터의 혼잣말·판단·도발·실수 반응으로 작성한다.

기술별 Bark를 무조건 등록하지 않고 실제 전투 시나리오에서 필요성이 확인된 문장만 DB 후보로 추출한다.

## 18. 소유·해금·성장 작성 규칙

### 18.1 초기 기술

초기 기술은 다음 요소를 근거로 배정한다.

- 직업·훈련
- 능력치
- 성격
- 과거 경험
- 기벽
- Memory Log
- 캐릭터 고유 설정

기본 기술 5종을 전원 자동 지급하지 않는다.

### 18.2 숙련과 변종

- 기본 기술 숙련은 안정성·조건 완화·연출 변화로 표현할 수 있다.
- 단순 수치 상위호환만 있는 변종은 금지한다.
- 변종은 자세, 대상 부위, 비용, 위험, 상호작용 중 하나 이상이 달라야 한다.

### 18.3 기벽 Return

기벽 Return은 기술 분류를 바꾸기보다 기술 노드에 선택적 효과를 추가하는 것을 우선한다.

예:

- 절정 여운 중 긴급 Tease 허용
- 자기 절정 비용 프로필 변경
- 특정 약점 공개 단계 보정
- 특정 부위 과자극 효과 변환

### 18.4 고유 능력

고유 능력은 단순 전 판정 +1보다 규칙 예외를 우선한다.

## 20. 기술 작성 절차

### STEP 1 — 전술 목적 한 문장 정의

```text
이 기술은 어떤 상황에서 무엇을 해결하는가?
```

### STEP 2 — 분류 선택

Service·Tease·Domination·Absorption·Defiance 중 실제 전술 역할을 선택한다.

### STEP 3 — 일반전투 기술 경계 검사

체력·무기·도주 중심이면 굴복 전용 기술에서 제외한다.

### STEP 4 — 목표 부위와 행동 부위 지정

대분류와 필요한 세부 부위를 선택한다.

### STEP 5 — 자세·점유·게이트 정의

사용 가능 자세, 결과 자세, 봉쇄되는 행동 부위를 기록한다.

### STEP 6 — 직접 효과와 자기 비용 분리

탈진력·굴복도·절정도·감응도 효과와 성공·실패 비용을 작성한다.

### STEP 7 — 대응 행동 작성

괴물 또는 생존자가 어떤 방식으로 대응할 수 있는지 정의한다.

### STEP 8 — 반복 공략 대응 검사

동일 부위 반복 시 보호·예측·자세 변화 가능성을 확인한다.

### STEP 9 — 전조·Narration 태그 작성

기술명을 직접 설명하지 않으면서 판단 가능한 단서를 정의한다.

### STEP 10 — 소유·해금 경로 작성

초기 기술, 학습, 기벽 Return, 고유 능력 연결을 기록한다.

### STEP 11 — 페이퍼 테스트

최소 다음 상황을 시험한다.

- 정상 성공
- 실패
- 부분 성공
- 약점 부위 공략
- Sensitive·Overstimulated 공략
- 보호 행동 대응
- 자세·행동 부위 제한
- 결정타 사용

### STEP 12 — 도감 등록

테스트 결과와 미확정 수치를 함께 기록해 Draft 상태로 등록한다.

## 21. 자동 검증 규칙

### 공통

- `side`는 `survivor`여야 한다.
- `phase`는 `submission`이어야 한다.
- `command_category`는 필수다.
- 목표 부위와 행동 부위를 혼합하면 오류다.
- 존재하지 않는 부위 키를 사용하면 오류다.
- 직접 효과와 자기 비용을 같은 필드에 기록하면 오류다.

### Service

- `exhaustion_damage` 또는 동등한 Control 목적이 없으면 경고다.
- 고위력인데 자기 비용·조건·쿨타임이 모두 없으면 오류다.

### Tease

- `counter_profile`이 없으면 오류다.
- 완전 카운터 성공 후 주도권 처리 정의가 없으면 오류다.

### Domination

- 조건·실패 비용·자기 비용 중 하나라도 없으면 경고다.
- 즉시 결착 기술은 명시적 승인 플래그가 없으면 오류다.

### Absorption

- 입력 공격축·물질이 없으면 오류다.
- 위험 또는 후유 효과가 전혀 없으면 경고다.

### Defiance

- 굴복도 회복이 +1을 초과하면서 희귀·상위 플래그가 없으면 경고다.
- 기본 기술이 절정 여운 행동 스킵을 무효화하면 오류다.

### 연출

- 행동을 알 수 없는 추상 기술명만 존재하면 경고다.
- 피니셔에 전조 프로필이 없으면 오류다.
- Bark 문장을 필수 출력으로 고정하면 경고다.

## 23. 기술 도감 제작 우선순위

### 1차 수직 슬라이스

성인 생존자 1명을 선정해 다음 규모를 권장한다.

- Service 2종
- Tease 2종
- Domination 1종
- Defiance 1종
- Absorption 0~1종

Absorption은 대상 괴물이 Fluid·Mutation 기술을 보유할 때만 포함한다.

### 2차 확장

- Mouth·Chest·LowerBody 부위별 기본 기술
- 후방·구속 대응 Tease
- 절정 여운·몰아붙임 대응 Defiance
- 약점 유형별 Domination

### 3차 도감화

- 캐릭터 고유 변종
- 기벽 Return 변종
- 비인간형 SpecialOrgan 기술
- 직업·성격 기반 기술
- 세력·훈련 계통 기술

## 24. 미확정 사항
